# Qairaq Клубы — тіркелу сайты

Оқушылар мен мұғалімдер клубқа тіркелетін жеңіл сайт әрі әкімші панелі.
Build жүйесі, Node.js, сервер — ешқайсысы керек емес: таза HTML + CSS + JS.

| Файл | Не үшін |
|---|---|
| `index.html` | Басты бет: клуб туралы, бағдарламалар, тіркелу формасы, байланыс |
| `admin.html` | Әкімші панелі: тіркелгендер тізімі, мәртебе, іздеу, CSV |
| `assets/config.js` | **Баптау** — Supabase кілттері, телефон, Instagram |
| `supabase-schema.sql` | Дерекқор кестесі + қауіпсіздік ережелері |
| `assets/petroglyph-bg.jpg` | Фон суреті |

Барлығы тегін: GitHub Pages (хостинг, домен, SSL) + Supabase (дерекқор).

---

## 1-қадам. Supabase дерекқорын жасау (≈3 минут)

1. [supabase.com](https://supabase.com) → **Start your project** → Google арқылы кіру
   (банк картасы сұралмайды).
2. **New project** → атын `qairaq` қойыңыз → аймақ: *Frankfurt* немесе
   *Singapore* → құпия сөз ойлап тауып, сақтап қойыңыз → **Create**.
3. Жоба дайын болған соң сол жақтан **SQL Editor** → **New query** →
   `supabase-schema.sql` файлының **бәрін** көшіріп қойыңыз → **Run**.
   «Success» деп шықса, кесте дайын.
4. **Project Settings → API** бөлімінен екі мәнді көшіріп алыңыз:
   - **Project URL**
   - **anon / public** кілті

## 2-қадам. Баптауды толтыру

`assets/config.js` файлын ашып, екі өрісті толтырыңыз:

```js
SUPABASE_URL: "https://xxxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
```

Instagram сілтемесі келгенде сол файлдағы `INSTAGRAM_URL` жолына қойыңыз —
сайт түймені автоматты көрсетеді (бос тұрса, «жақында қосылады» деп тұрады).

> `anon` кілтті жариялаудан қорықпаңыз — ол әдейі браузерге арналған.
> Деректерді кім оқитынын Supabase ережелері шешеді: бөтен адам тек
> **тіркеле** алады, тізімді **тек әкімші** көреді.

## 3-қадам. Әкімші аккаунтын жасау

Supabase → **Authentication → Users → Add user → Create new user**:
поштаңыз бен құпия сөз жазып, **Auto Confirm User** белгісін қойыңыз.

Осы поштамен `admin.html` бетіне кіресіз.

## 4-қадам. GitHub Pages-ке жүктеу (тегін хостинг)

1. GitHub-та жаңа репозиторий жасаңыз: `qairaq-club` (Public).
2. Осы қалтадағы файлдарды сол репозиторийге жүктеңіз
   (GitHub бетіндегі **Add file → Upload files** арқылы да болады).
3. Репозиторий → **Settings → Pages** → *Source*: **Deploy from a branch** →
   Branch: `main`, қалта: `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<аккаунт>.github.io/qairaq-club/`
   Әкімші панелі: `https://<аккаунт>.github.io/qairaq-club/admin.html`

Жеке домен қосқыңыз келсе, сол **Pages** бөлімінде *Custom domain* өрісі бар.

## Жергілікті тексеру

Файлдарды жай екі рет шертіп ашуға болады, бірақ кейбір браузер модульдерге
шектеу қоятындықтан кішкентай сервер арқылы ашқан дұрыс:

```bash
cd qairaq-club
python -m http.server 8080
# сосын браузерде: http://localhost:8080
```

## Форма өрістері

1. Оқушы / мұғалім
2. Тегі
3. Аты
4. Сыныбы — тек оқушы таңдағанда көрінеді
5. Мектебі

Мұғалім таңдалса «сыныбы» өрісі жасырылады, ал «мектебі» деген жазу
«жұмыс істейтін мектебі» болып өзгереді.

## Әкімші панелі не істейді

- Тіркелгендердің **тегі, аты, рөлі, сыныбы, мектебі, тіркелген күні** (Алматы уақытымен)
- Жалпы статистика: барлығы / оқушы / мұғалім / жаңа өтініш
- Әр өтініштің мәртебесін ауыстыру: Жаңа → Қаралуда → Қабылданды / Қабылданбады
- Аты, тегі, мектебі бойынша іздеу; рөл мен мәртебе бойынша сүзгі
- **CSV жүктеу** — Excel-де ашуға дайын (қазақша әріптер дұрыс көрінеді)
